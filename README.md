# Karenode landing page

Static Arabic RTL landing page. Upload the contents of this folder to a GitHub Pages repository; no build step or backend is needed.

Before publishing:
1. Set `whatsappNumber`, `facebookPageName`, and `facebookPageUrl` near the top of `script.js`. Use an international WhatsApp number containing digits only. The WhatsApp and Facebook buttons remain inactive until their destinations are configured.
2. Replace the two sample offer images and the placeholder copy in `index.html` with real product/course details, availability, and verified claims. No prices or results are invented in this version.
3. Review the contact text, policies, and whether `kyrostack.com` is the intended public link.

Images `product-placeholder.png` and `course-placeholder.png` are generated concept photographs. `logo.jpg` and `cover.jpg` were supplied by the user.
